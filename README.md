# mjaret_codesample_2026

This coding sample was created in August 2026 and is based on my senior capstone research from Susquehanna University. The research centers on the impacts of wildfires on housing prices in California. The sample provides the construction of my panel data set spanning 312 months and 478 cities, my empirical strategy including regressions associated robustness checks, and the creation of plots and tables to assist myself and readers to analyze the data. As such, I separate the code script into three sections found in the "R" folder: 1) mjaret_dataconstruction.R, 2) mjaret_regressions.R, and 3) mjaret_tables_plots.R.

The data construction walks through the cleaning, harmonizing, and preparing of raw city, fire, housing, and weather data. A guide to the data sources can be found in the "README.md" file in the "raw_data" folder. I derive my own continuous exposure measure using a exponential decay function, considering the magnitude, duration, and distance of the fire, and apply it to each month and city within the panel dataset. As an alternative, I define two distance-based bin exposure measures: binary and days bins. The binary bin considers if a fire within the distance of the city while the days bin considers how many days in the month at least one fire is active. The data construction shows the derivation dependent variable, housing prices, using the ZHVI dataset. Following, I collect weather data from the PRISM data set to use as control variables. Finally, I combine all variables into a large panel data set to use for my regressions.

The regressions portion of the sample sets up and runs regressions. I use an event study design using a continuous treatment and endpoint binning as explored in Schmidheiny & Seigloch (2023), allowing me to analyze effects before and after exposure occurs. Regressions are ran for each of three exposure variables, and I analyze results by testing the joint nullity of the lag coefficients. For each of the regressions, I consider robustness checks. For example, I run regressions of the continuous exposure model with and without endpoint binning as well as varying exponential decay parameters. I also check how differing standard error specifications affect results. My primary models use two-way cluster robust standard errors following Cameron & Miller (2015), but I consider Conley spatial errors (Conley, 1999) and Driscoll-Kraay errors (Driscoll & Kraay, 1998) as well. I collect each output to later create plots and tables to more easily analyze trends.

The final portion creates plots and tables to present tables of my data and visualize the outputs of my models. For example, I create a table presenting the summary statistics (mean, median, standard deviation, etc.) of my panel dataset. I use packages such as "ggplot2", "fixest", and "xtable" to create these plots and tables. I import from the "source_data" folder which contains the outputs from the regressions ran in the "mjaret_regressions.R" script. I output the plots as .pdf's to enhance the images. The tables are exported as .tex's to upload into LaTeX code, which is the language I used to write my project. The resulting tables and plots can be found in the "tables_plots" folder.

The "00_run_all.R" file runs all three scripts found in folder "R".
