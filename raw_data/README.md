This file presents the links to the raw data used in my project. Due to licensing and size concerns, I do not provide downloads to this data.

Zillow Home Value Index Data:
Name: ZHVI All Homes (SFR, Condo/Co-op) Time Series, Smoothed, Seasonally Adjusted($)
File: 'City_zhvi_uc_sfrcondo_tier_0.33_0.67_sm_sa_month.csv'
Link: https://www.zillow.com/research/data/

Name: Historical Fire Perimeters
File: 'fire25_1.gdb'
Link: https://www.fire.ca.gov/what-we-do/fire-resource-assessment-program/fire-perimeters

2020 Census Block Data:
Name: Tiger/Line Shapefile, Current, State, California, 2020 Census Block
File: 'tl_2025_06_tabblock20.zip'
Link: https://catalog.data.gov/dataset/tiger-line-shapefile-current-state-california-2020-census-block

PRISM Weather Data:
Name: PRISM Data Explorer: Download Time Series Values in Bulk
File (2000-2014): 'PRISM_ppt_tmean_stable_800m_200001_201412.csv'
File (2015-2025): 'PRISM_ppt_tmean_stable_800m_201501_202512.csv'
Link: https://prism.oregonstate.edu/explorer/bulk.php
Note: The data extraction requires the 'prism_cities_ll.csv' file created in 'mjaret_dataconstruction.R' and can be found in the 'source_data' folder in the repository
